# Rohan Lall — Portfolio

A modern, responsive developer portfolio built to showcase my projects, technical skills, and experience. The application includes a contact form with a Node.js/Express backend and MongoDB for storing messages.

## Features

- Responsive and modern UI
- Dark terminal-inspired design
- Contact form with backend integration
- MongoDB database for contact submissions
- Admin dashboard to manage contact messages
- Fast and optimized performance

## Tech Stack 

- React
- JavaScript
- Node.js
- Express.js
- MongoDB
- HTML5
- CSS3

## Installation

```bash
git clone <repository-url>
cd portfolio
npm install
```

Create a `.env` file:

```env
MONGODB_URI=your_mongodb_connection_string
ADMIN_KEY=your_admin_key
```

Run the project:

```bash
npm start
```
