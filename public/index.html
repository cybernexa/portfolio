I'm Rohan Lall, a BCA graduate who got into development through the side door of networking and hardware — I can trace a packet through the OSI model as comfortably as I can trace a bug through a React component tree.

That background shows up in how I build: I care about what's actually happening under the UI — the requests, the database, the auth token bouncing between client and server — not just how a page looks. My recent internship had me building real Oracle APEX applications end to end: UI, SQL, and the bug fixes in between.

Outside of shipped work, I keep a running list of networking & security concepts I'm teaching to others through my own tutorial site — turns out explaining DNS resolution to strangers is a great way to make sure you actually understand it.
